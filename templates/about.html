About FitPulse

An engineering project bridging sports science and modern web architecture.

Our Mission

Democratizing Intelligent Training

FitPulse was designed from the ground up to solve the clutter and misinformation prevalent in modern fitness culture. Instead of endless subscriptions and convoluted workout routines, we provide evidence-based hypertrophy splits, clear exercise biomechanics, and personalized health metrics.

Built as a comprehensive college capstone project, this platform demonstrates full-stack software development principles: secure authentication, relational database modeling, responsive mobile design, and cloud readiness.

Key Architecture Concepts to Explain

Clear explanations for examiners and professors reviewing this project.

1. MVC Architectural Pattern

Models (models.py): Encapsulate the PostgreSQL schema and relationships.
Views (templates/*.html): Jinja2 templates for dynamic semantic presentation.
Controllers (app.py): Route handlers processing incoming HTTP requests and dispatching data.

2. Security & Password Hashing

Passwords are never stored in plaintext. Werkzeug's generate_password_hash implements industry standard cryptographic PBKDF2/scrypt salt-and-hash routines. Protected routes use session-based authentication with custom @login_required guards.

3. SQL Injection Prevention

By using SQLAlchemy ORM queries (such as Workout.query.filter()), all search inputs and route parameters are automatically bound as parameterized variables by the DB-API driver, neutralizing SQL injection vectors.

4. Asynchronous AJAX Favorites

The favorite/bookmark feature uses JavaScript fetch() API to interact with /api/favorites/toggle/<id> asynchronously, updating the database record and toggling the UI heart icon without triggering an expensive full page reload.
